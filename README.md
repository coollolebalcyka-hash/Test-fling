# 🪐 Планета — мессенджер

**Планета** — это мессенджер для Android (APK), в котором можно общаться, обмениваться файлами, звонить, включать камеру и показывать демонстрацию экрана.

---

## 📥 Установка

1. Скачайте APK-файл приложения **Планета**.
2. В настройках телефона разрешите установку из неизвестных источников.
3. Откройте скачанный APK и установите приложение.
4. Запустите **Планету**.

---

## 🔐 Регистрация и вход

1. При первом запуске нужно **зарегистрироваться** или **войти**.
2. Введите **номер телефона**.
   > ⚠️ SMS-код **не приходит** — подтверждение по SMS не требуется.
3. Укажите **имя**. **Фамилию можно не писать** (поле необязательное).
4. Готово — открывается главное **меню** приложения.

---

## ✨ Возможности

| Функция | Описание |
| --- | --- |
| 🔍 Поиск пользователей | Найдите собеседников **по имени** |
| 💬 Общение | Переписывайтесь с другими пользователями |
| 📎 Отправка файлов | Скидывайте файлы форматов **`.txt`**, **`.apk`**, **`.exe`** |
| 📞 Звонки | Звоните другим пользователям |
| 🖥️ Демонстрация экрана | Показывайте свой экран собеседнику |
| 📷 Камера | Включайте камеру во время связи |

---

## 🚀 Как пользоваться

1. Зарегистрируйтесь или войдите по номеру телефона.
2. Введите имя (фамилия — по желанию).
3. В меню найдите нужного пользователя **по имени**.
4. Начните общение: пишите сообщения и **отправляйте файлы** (`txt`, `apk`, `exe`).
5. Совершайте **звонки**, включайте **камеру** и запускайте **демонстрацию экрана**.
